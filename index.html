진행 순서

업데이트 전에 파일과 기기 상태를 모두 검사합니다.

1. 펌웨어 파일 선택

벤더 배포처에서 받은 좌우 파일을 선택합니다. 파일은 브라우저 안에서만 읽고, 사이트로 업로드하지 않습니다.

2. 기기 연결과 사전 검사

제품, 모듈, 현재 버전, 배터리, 파티션, 상태를 읽습니다. 60% 미만이거나 상태가 맞지 않으면 전송하지 않습니다.

3. 전송과 확인

양쪽 전송이 끝나고 무결성 확인이 통과한 뒤에만 적용합니다. 완료 후 다시 연결해 양쪽 버전을 확인합니다.

macOS는 왜 앱이 필요한가요?

Chrome의 RFCOMM 채널 문제

macOS가 이 기기의 Airoha 서비스를 알려줄 때 RFCOMM 채널을 1로 반환하지만, 실제 FOTA 채널은 3입니다. Chrome의 Web Serial은 반환된 1로 연결을 시도하고, 웹 API에는 채널을 직접 고르는 기능이 없습니다.

Web Bluetooth에는 서비스가 없음

이 기기는 클래식 SPP만 노출합니다. 주변 BLE를 스캔해도 Airoha FOTA 서비스가 나타나지 않아 Web Bluetooth로 대체할 수 없습니다.
