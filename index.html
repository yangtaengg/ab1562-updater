macOS는 왜 앱이 필요한가요?

Chrome의 RFCOMM 채널 문제

macOS가 이 기기의 Airoha 서비스를 알려줄 때 RFCOMM 채널을 1로 반환하지만 실제 FOTA 채널은 3입니다. Chrome의 Web Serial은 1로 연결을 시도하고, 웹 API에는 채널을 직접 고르는 기능이 없습니다.

그래서 앱이 연결을 담당합니다

앱이 실제 SDP 레코드에서 채널 3을 읽어 연결합니다. 앱은 127.0.0.1에서만 요청을 받고, 사용자가 확인하기 전에는 기기 변경 명령을 거절합니다.
