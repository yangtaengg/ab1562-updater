포함된 패키지

앱에 지원 기기용 좌우 펌웨어가 포함되어 있습니다. 사용자가 파일을 고를 필요가 없습니다. 앱은 연결 후 제품과 버전을 확인하고, 지원 목록과 일치할 때만 전송합니다.

업데이트 순서

  1. 이어폰 양쪽을 60% 이상 충전하고 케이스에서 꺼냅니다.
  2. macOS 앱을 실행하고 Bluetooth 접근을 허용합니다.
  3. 기기 연결하기를 누르고 제품, 버전, 배터리, 상태 검사를 기다립니다.
  4. 업데이트 버튼을 누르고 확인 창에서 시작합니다. 완료될 때까지 창을 닫지 마세요.
  5. 기기가 재시작되면 다시 연결하기를 눌러 양쪽 버전을 확인합니다.
중간에 끊기면 앱이 임의로 Commit을 다시 보내지 않습니다. 다시 연결해서 양쪽 상태를 읽고, 이미 전송된 쪽은 SHA-256을 비교해 건너뜁니다.

macOS 연결 방식

Chrome의 Web Serial은 macOS가 알려주는 RFCOMM 채널 1로 열려고 하지만 실제 FOTA 채널은 3입니다. 웹 API에는 채널 선택 기능이 없습니다. 앱이 SDP 레코드에서 채널 3을 직접 읽어 연결하고, 화면은 앱 안에서만 엽니다.

앱은 127.0.0.1에서만 요청을 받고, 사용자가 확인하기 전에는 기기 변경 명령을 거절합니다.

자주 묻는 질문

파일을 골라야 하나요?

아니요. 지원 패키지가 앱에 포함되어 있습니다. 앱이 연결 후 지원 여부를 확인합니다.

업데이트 후 버전이 안 바뀌었어요.

Commit 응답이 유실됐을 수 있습니다. 다시 전송하지 말고 재연결해서 양쪽 버전과 상태를 확인하세요. 앱은 확인된 버전만 완료로 기록합니다.

배터리가 부족하다고 나옵니다.

양쪽 모두 60% 이상이어야 합니다. 충전 후 다시 연결하세요.

다른 모델도 되나요?

지원하지 않습니다. 유사한 AB1562 계열이라도 파티션과 프로토콜이 다를 수 있습니다.

Intel Mac에서 되나요?

현재 베타는 arm64 전용입니다. Intel 빌드는 아직 없습니다.

로그를 보내려면?

앱 창의 로그와 기기 상태, 버전을 함께 보내 주세요. 로그는 ~/Library/Logs/FlyCCConnector.log에도 남습니다.
